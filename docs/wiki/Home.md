# GitCraft: управление Minecraft через Git

GitCraft отделяет **одобренные настройки** от **игровых данных и исполняемых файлов**. Разработчик меняет конфиг в ветке, открывает PR, команда проверяет изменение, а агент устанавливает точный коммит настроенной ветки, когда Minecraft пуст.

Это документация проекта для разработчиков и администраторов. Команды ниже исполняются вами на выбранной машине; они не означают, что установка или перенос уже выполнены авторами проекта.

## Начать

1. [Быстрый старт](Quickstart.md) — путь от локального сервера к Git и VPS.
2. [Полные настройки и операции в панели](Operations.md) — bootstrap, credentials, maintenance, recovery и backup без ручного YAML.
3. [Экспорт и политика Git](Export-and-policy.md) — выбрать только нужные конфиги, просмотреть план, закрепить JAR.
4. [Новый VPS и перенос](Transfer.md) — передать миры и JAR напрямую, проверить, продолжить прерванную загрузку.
5. [Подключить работающий сервер](Adoption.md) — сохранить существующие unit, Java, мир и RCON.
6. [Ветки и Pull Request](Pull-requests.md) — предложить изменение без прямого релиза.
